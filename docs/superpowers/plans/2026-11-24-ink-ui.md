# Giao diện thủy mặc Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the dark "imperial" look with the approved ink-wash (thủy mặc) design on `/`, `/products`, `/products/[slug]`, the nav and the footer, without touching data or query logic.

**Architecture:** New presentational building blocks in `components/ink/`, pure display helpers in `lib/display.ts` (unit-tested), new colour tokens added alongside (not replacing) the old Tailwind scales. Pages are recomposed from these blocks; existing data functions in `lib/db/products.ts` and filter/search/pagination logic stay as they are. Visual work is verified in the browser at 375 / 768 / 1280 px.

**Tech Stack:** Next.js 15 App Router, React 19, Tailwind 3, shadcn/ui, framer-motion (already installed), Vitest (node env, pure functions only), `next/font/google`.

**Spec:** `docs/superpowers/specs/2026-11-24-ink-ui-design.md` · Mockups: `docs/superpowers/specs/2026-11-24-ink-ui-mockups/home.html`, `product-card.html` (their `/files/x.webp` = `public/ink/x.webp`).

## Global Constraints

- Colours (new tokens only): `paper #F4EFE4`, `paper-2 #ECE4D3`, `ink #1C1B19`, `ink-2 #5A554C`, `gold #B8913A`, `gold-2 #E2C57C`, `seal #A8281F`. Do not change the existing `primary`/`accent`/`neutral`/`cyphr` scales in `tailwind.config.ts`.
- Fonts: Cormorant Garamond (300/400/500 + italic) for headings, product names, big prices; Be Vietnam Pro (300/400/500) for body. Both with `subsets: ['latin','vietnamese']`.
- Page background: `paper` + `public/ink/paper-tile.webp` repeated at 512px.
- Ink art on white background uses `mix-blend-mode: multiply` on the element whose parent is not an isolated group; put the blend on any wrapper that has `transform`/`will-change`/`z-index`/`filter`. Transparent art (`brush-*`, `seal-*`) uses normal blend.
- Never apply CSS `filter` to a product photo. Deckle on photos is done with a `mask-image` only.
- Gold brush stroke only behind ink-coloured text, never next to gold text.
- No Hán characters, dragons/phoenixes, vertical Vietnamese text, uppercase-tracked product names.
- Contact: Zalo `https://zalo.me/0937033468`, phone `tel:0937033468`, Facebook `https://www.facebook.com/tramhuongsonhong.vn` — read from `config/content.ts`, not hard-coded in components.
- All motion disabled under `prefers-reduced-motion: reduce` (content shown immediately). Cursor ink only on fine pointers (`(pointer: fine)`).
- No new runtime dependencies. No schema/query/API changes. No horizontal scroll from 375px to 1440px+.
- Run package scripts via `corepack pnpm@9.15.9 …` (pnpm is not on PATH).

## Review Focus

1. Product with no images (or a broken image URL) — card and detail page show a paper placeholder, not a broken icon or collapsed box. (Task 4, 5)
2. Product whose every variant has price 0 / null — shows "Liên hệ", never "0₫". (Task 1 test `formatPrice`)
3. Variant list where all variants are out of stock, or `track_inventory` false — default selection still works; "Hết hàng" only when tracked and quantity ≤ 0. (Task 1 test `pickDefaultVariant`, `isSoldOut`)
4. Very long product names (some are 80+ chars, all caps in data) — sentence-cased, wrap to max 3 lines on cards without breaking layout. (Task 1 test `toSentenceCase`, Task 4 line-clamp)
5. Reduced-motion users and touch devices — hero, seal stamp and reveals show final state; no cursor canvas on touch. (Task 2 `useReducedMotion` usage, checked in Task 8)

### Task 2: Ink building blocks

**Files:** Create in `components/ink/`: `Seal.tsx`, `InkArt.tsx`, `Brush.tsx`, `Ornaments.tsx`, `Reveal.tsx`, `InkCursor.tsx`, `PaperFrame.tsx`, `ink.css` (imported once from `app/globals.css`).

**Interfaces:**
- Consumes: tokens/fonts from Task 1.
- Produces:
  - `<Seal size?: 'sm' | 'lg'; className?: string />` — `sm` (default, <100px): `seal-blank.webp` + "SƠN/HỒNG" text in paper colour masked by `seal-texture.webp`; `lg`: `seal-full.webp`. Prop `stamp?: boolean` plays the stamp-in animation (scale 1.7, rotate −12° → 1, −4°; 0.55s, delay prop `delayMs`).
  - `<InkArt src: string; alt?: string; feather?: 'radial' | 'x' | 'none'; className?: string />` — `<img>` with `mix-blend-mode: multiply` and optional feather mask.
  - `<BrushStroke variant: 'gold' | 'ink'; className?: string; animate?: boolean />` — transparent stroke, optional left-to-right clip reveal.
  - `<FretCorner className />`, `<FretBand className />` (repeat-x SVG strip), `<DrumFace className />` (simplified Đông Sơn face, gold strokes).
  - `<Reveal delayMs?: number; className?: string>{children}</Reveal>` — IntersectionObserver, blur 6px + 28px lift → none; renders final state when reduced motion.
  - `<InkCursor />` — absolutely positioned canvas filling its parent; ink drops (≈15% gold) on pointermove, fade 2.6s; no-op on `(pointer: coarse)` or reduced motion.
  - `<PaperFrame hoverLift?: boolean; className?: string>{children}</PaperFrame>` — 6px deckled paper mat: deckle `filter` only on `::before`; children wrapped in a box with the photo-edge `mask-image` (displacement scale 0.5, baseFrequency .22); hover border via `::after` (1.5px gold, same filter). Values copied from `product-card.html` mục C.
